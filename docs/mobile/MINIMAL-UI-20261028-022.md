# Android 0.2.2 — compact phone layout

Date: 2026-10-28. Android versionCode 23; desktop version unchanged.

## Changes

- Four tabs: Axx, Chat, Actions and PC. Removed the promotional heading and repeated instructions from the home screen.
- The character fills the available home area. Gestures and microphone settings expand on demand.
- Chat messages scroll inside their own pane. The composer stays above navigation when the viewport shrinks for the keyboard; drafts survive pane switches and refreshes.
- Applications, search, notes, activity, permissions and raw execution receipts remain available in expandable sections. Remote input labels and statuses are in Spanish.
- Android accessibility text scaling remains enabled. The layout supports narrow screens rather than forcing the device's font preference back to 100%.
- Color, shape, material, lighting and camera still come from the PC snapshot and the exact shared desktop renderer. No second appearance configuration was introduced.

## Verification and limits

All 10 browser tests passed. They check a 339 × 673 px viewport, text scaled to 170%, a 380 px keyboard viewport, visible navigation and composer, draft retention, changing PC palette/material/exposure, safe pairing rejection, ordered input, Stop and no automatic replay after lost acknowledgements. Browser tests explicitly supply a native fixture; they are not physical Android acceptance.

Its 69-item executable catalog loaded, and the typed Work order `estado del sistema` reached Windows with `state=succeeded` and `postconditions_passed=true`. An old unresolved read-only telemetry tracker was discarded locally before that test, without replaying the old operation. A PC restart during the session was followed by successful phone reconnection.

Earlier browser QR decoding and historical phone-control receipts do not close those gates.
