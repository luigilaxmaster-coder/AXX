# Cinco imágenes de presentación · Axx 0.22.23

Capturadas el **29 de octubre de 2026** a partir del frontend de la revisión
`271024d2bf276f3882561f9fc3bafe5fbab304df`. El código de la aplicación no se modificó
para producirlas. Son cinco PNG de **1600 × 1000 píxeles**, con DPR 1, generados en
Chromium aislado mediante Playwright ya disponible en el entorno del proyecto.

Se utilizó `1.AXX/Axx.html` servido en loopback. El avatar, los controles y los
paneles proceden del renderer y los componentes reales. Se añadió una capa
editorial de títulos, fondo, tamaños y posición para el encuadre de documentación.
No son capturas sin editar del escritorio instalado ni de una sesión nativa.
Los PNG no se retocaron después de su captura.

El contexto de navegador fue nuevo para cada imagen. No se usaron el perfil del
navegador personal, conversaciones, capturas de pantalla del usuario, tokens,
claves de API, códigos de emparejamiento ni voces. No se ejecutó ninguna acción
del equipo, no se autorizó Computer Use y no se envió una captura a un modelo.

En Magic Pen se muestran los componentes antes de capturar, con un rótulo
editorial explicativo; no se fabrica una respuesta de visión. La vista API
permanece sin una conexión personal seleccionada. Las imágenes acreditan su
procedencia visual, no autenticación, conectividad, inferencia, audio o ejecución.
Para aceptación funcional, consultar las [notas de 0.22.23](../../../releases/0.22.23.md).
