# Axx 0.20.18 — Windows x64 test release

- Persistent phone permissions with separate control and Work approval.
- Remote avatar Rotate/Move events and improved Work command/results UI.
- PowerShell/CMD requests require explicit approval of the exact text on the PC.
- Native local Ollama text streaming, background model preload and configurable response style.
- Windows voice plus optional local Axx Alba, Nova, Aura and Titán voices; speech text cleanup.
- Longer first-start backend allowance and improved startup verification.

The Windows installer was installed and launched successfully with an authenticated
backend and visible native window. Validation included 38 Python tests, 15 Rust
tests (one additional test ignored), 18 desktop interface checks and 9 chat checks.

Custom voices require a separate local MOSS installation and user-supplied audio.
Neither model weights nor user voice samples are included. On the development PC,
custom speech took about 63 seconds cold and 7 seconds warm; this is not real-time
voice. Local chat first text arrived in about 1.8 seconds after model preload.
These timings are measurements on that PC, not performance guarantees.

Android 0.1.3 was built locally; installation and Rotate/Move/Work validation on
the physical phone remain pending. Android APKs are not included in this release.
The installer is unsigned and may require WebView2 installation. Configure your
own AI provider in Settings. Verify the download against `SHA256SUMS.txt`.
