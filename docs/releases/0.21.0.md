# Axx 0.21.0 · Automatic free inference and reusable skills

This release adds a visible skill library, typed variations, project context,
durable tasks and explicitly free model selection while preserving the existing
native interface and command approval boundary.

- New installations start with **Automático gratis · Sin claves**. Axx prepares
  Kilo Gateway, OVHcloud AI Endpoints and AI Horde through FreeLLMAPI, discovers
  real anonymous routes and evaluates each task before activation. Personal keys
  are optional; unavailable or insufficiently described models stay pending.
- Initial user-proposed model IDs are retained as candidates. Catalog mapping and
  representative evaluations distinguish provider/native/gateway identities;
  simulated tests cannot activate a production preference.
- FreeLLMAPI integration targets **0.16.9**, commit
  `26484157fd15f5fb66f54d3a86f568997ea304de`. Axx can own a pinned local source
  installation or connect to an external URL. Credentials stay in the backend.
- **Mis habilidades** supports examples, favorites, project aliases, typed
  parameters, immutable revisions, outcome confirmation and composition.
  Reusing a deterministic skill needs no model call. An optional content stage
  creates new writing, translation or code before command approval.
- Tasks retain step identities, inputs, receipts and model routing history.
  Restart recovery skips confirmed effects. Repair retains completed steps;
  uncertain effects require reconciliation. Waiting for model capacity retains
  the task and retries planning without automatically approving effects.
- **Aprende esto** observes bounded accessibility events in a selected Windows
  window. Observation is candidate evidence; playback still requires supported,
  validated CommandService commands. Recording alone does not verify a skill.

See [setup, usage and validation](../automatic-skills.md). Anonymous setup requires Internet access and service availability. Kilo records
prompts and responses for training; these routes reject requests marked sensitive.
No paid API is used as an automatic fallback. Application-specific CAD, Revit,
SketchUp and Photoshop replay is not advertised as implemented.

## Validation

- 164 backend tests, 94 inference/gateway/candidate tests and 31 mobile tests passed.
- 12 release-tool tests passed; provider UI, 9 chat checks, 33 Axx Connect checks
  and both source and frozen-backend browser integrations passed.
- The source integration uses controlled model responses with actual files,
  SQLite, command approval and the real local gateway. It verifies learned
  parameter variations with zero model calls and separate execution identities.
- A clean FreeLLMAPI installation downloaded a verified official Node archive
  and pinned source archive, built successfully, started and passed idempotent
  reinstall and modified-source preservation checks.
- Public anonymous connectivity succeeded for Kilo Liquid, Kilo Cohere and OVH
  Mistral Small. Cohere North Mini Code then passed exact gateway planning and
  conversation fixtures (about 4.2 s / 2.9 s). Parameters, repair, code, writing
  and translation also passed (2.1–8.4 s), one request per task, zero corrections.
  All seven preferences persisted; restarting reused plan/chat evidence without
  another inference. These are representative checks, not broad intelligence benchmarks.
- OVH's observed 429 cooldown expired normally. AI Horde was not activated
  because its catalog did not supply verifiable context capacity. Vision stays
  pending when no tested route meets the image requirements.

Kilo, OVH and AI Horde availability and anonymous quotas can change. Proposed
personal-key model IDs stay pending until an actual eligible account/catalog and
representative task result confirm them. Existing deterministic skills remain
usable without model availability.
