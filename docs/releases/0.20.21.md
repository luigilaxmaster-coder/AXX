# Axx 0.20.21 — Restore the phone pairing QR

The Windows backend was packaged without `qrcode`. Pressing **Mostrar QR nuevo**
failed with HTTP 500 (`ModuleNotFoundError: No module named 'qrcode'`). The mobile
status refresh then replaced the error with the gateway's normal connection
status, making the button appear to do nothing.

- Include the QR package and SVG renderer in the Windows backend. The build uses
  the existing `qrcode==8.2` dependency from `requirements-mobile.txt`.
- Check real SVG generation before packaging and again by executing the packaged
  backend with `--verify-mobile-qr`. A missing renderer now fails delivery before
  the Windows installer is built. This check creates no pairing or user state.
- Display pairing errors in a persistent alert, separate from connection status.
- Show the QR immediately after generation, without waiting for history sync.
- Use a white SVG background, retain the quiet zone and the existing 120-second,
  one-use pairing policy. TLS pinning and per-phone permissions are unchanged.

Validation: eight gateway/QR tests, including the real management route and
one-use claim; browser checks for error persistence, immediate QR display while
history is pending, and QR expiration. Native verification is recorded after
installation. Review is by the implementing agent, without an independent reviewer.

Installed Windows verification: the settings button displayed a loaded QR with
its countdown and no pairing error. OpenCV decoded the actual native screenshot
to exactly the pairing link supplied by Axx (compared by SHA-256, without logging
the link). Both source and packaged QR-render checks passed. Twelve release
workflow tests passed. One native process exit (Windows event 1000, 0xc0000409)
occurred on the first automated settings open after installation; reopening the
same binary succeeded. Its cause remains unconfirmed; this is not a general
native-stability certification.

Android is unchanged. USB/ADB did not enumerate the phone during diagnosis;
displaying/decoding the PC QR does not establish a physical phone connection.
The installer is unsigned. No pairing codes or user data are published.
