# Axx 0.21.12 — rutas de voz y comandos de escritorio

## Cambios

- El chat de voz envía el texto final sin una espera adicional de 1,3 segundos. Si la transcripción repite palabras o queda vacía, Voz en vivo informa el fallo y vuelve a escuchar cuando es recuperable.
- El panel muestra el tiempo aproximado desde la última voz detectada hasta el primer audio, además del tiempo de transcripción. Es una medida local por turno, no una garantía de dos segundos.
- Las frases «en Chrome busca…», «abre yotube» y «ponme en Spotify…» se resuelven como acciones tipadas. Las búsquedas dirigidas a Spotify ya no se envían a YouTube. Abrir resultados de Spotify no confirma que una canción esté reproduciéndose.
- Si Windows tarda o falla al actualizar su inventario, Axx conserva los últimos accesos observados para intentar abrir la aplicación. Windows vuelve a validar el acceso al lanzarla.
- Tras abrir una aplicación instalada, Axx observa también ventanas visibles que aún no están en primer plano; con el control de entrada local intenta enfocar una ventana única y registra por separado apertura, foco y disponibilidad para actuar.
- El motor local usa `faster-whisper-base` cuando los cuatro archivos completos están en `%LOCALAPPDATA%\Axx\models\faster-whisper-base`; en otros equipos mantiene el modelo Tiny incluido en el instalador.

## Verificación y límites

- Una muestra de voz **sintetizada en inglés con nombres españoles** tardó 1,27 s en Tiny y 1,63 s en Base, incluida la carga del modelo. Base reconoció más palabras de esa muestra, pero el resultado no representa un micrófono real ni garantiza mejor calidad en todas las voces.
- Pendiente: prueba física con el micrófono del usuario, reproducción real de una pista de Spotify y aceptación visual de cada aplicación instalada. La búsqueda en Chrome usa el navegador predeterminado; en el equipo evaluado, Windows tiene Chrome como predeterminado.
- El instalador público conserva Tiny; el modelo Base opcional de este PC no se publica, ni se incluyen muestras de voz o datos de ejecución.
