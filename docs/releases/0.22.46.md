# Axx 0.22.46 — Corrección y mejora de FreeLLMAPI, Google Gemini y presupuesto de contratos 3D

## Cambios

- **Presupuesto de contratos ampliado a 48.000 caracteres (`backend/prompts.py`).** Se incrementó `MAX_INSTRUCTIONS` de 24.000 a 48.000 caracteres. Esto elimina el error `El contrato completo supera el presupuesto; no se envió ni truncó` al solicitar modelos 3D en Magic Pen con el catálogo completo de 178 componentes y 50 formas geométricas especializadas.
- **Corrección integral de FreeLLMAPI y prueba de conexiones (`backend/server.py`, `backend/inference/router.py`, `backend/inference/provider_settings.py`).**
  - Se solucionó el error `NO_PROVIDER_AVAILABLE (HTTP 502)` al pulsar "Probar respuesta": la comprobación interna `/axx-api/providers/probe` detecta las tareas soportadas por el proveedor y marca la petición como prueba de conectividad explícita, evitando bloqueos por `candidate_only` o disparidad de tareas.
  - Al guardar conexiones desde la interfaz (`provider_settings.py`), se desactiva `candidate_only` para que la conexión quede lista para uso inmediato.
  - Se actualizaron las rutas y modelos anónimos del gateway FreeLLMAPI a modelos vigentes y probados en vivo con respuesta HTTP 200 (`cohere/north-mini-code:free`, `Mistral-Small-3.2-24B-Instruct-2506` y `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free`).
- **Autenticación nativa y normalización para Google Gemini (`backend/inference/router.py`, `backend/inference/provider_settings.py`, `backend/magic_pen.py`).**
  - Inyección de cabeceras de API key de Google (`x-goog-api-key` y `api-key`) junto con `Authorization: Bearer` en el endpoint OpenAI-compatible de Google AI Studio.
  - Normalización automática de nombres de modelos quitando el prefijo `models/` (e.g. `models/gemini-3.6-flash` -> `gemini-3.6-flash`).
  - Actualización transparente de modelos retirados por Google a variantes activas recomendadas (`gemini-3.6-flash` / `gemini-3.5-flash`).
  - Ampliación del límite de tokens en la prueba de aptitud visual de Magic Pen de 1.500 a 4.096 tokens para permitir el procesamiento del razonamiento interno de Gemini sin truncamiento de la escena 3D JSON.
