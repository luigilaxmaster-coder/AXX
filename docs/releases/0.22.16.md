# Axx 0.22.16 — Mobile companion

Android is an extension of the running Windows Axx. This update retains the
desktop character, existing remote input and voice, credentials and permissions.

- Pair without enabling chat history. When history sharing is off, the phone
  receives no shared messages and cannot submit to the shared chat. Work remains
  available with its separate PC permission.
- Rescan a fresh QR for the same PC without creating a duplicate device or losing
  grants. The native client presents its stored credential only when the QR
  fingerprint matches. Codes remain single-use and expire after two minutes;
  revoked credentials cannot recover grants.
- The phone follows desktop appearance, active shared conversation, selected
  model and current permissions. Foreground snapshots and desktop conversation
  sync poll every two seconds; this is polling, not a guaranteed latency.
- The executable catalog comes from the live desktop registry, including enabled
  MCP tools and approved generated capabilities. Documentary entries and disabled
  tools are excluded. Sensitive operations still require PC approval.
- Chat commands use the desktop resolver for every message rather than a mobile
  verb-prefix list. Conversational text falls through to the configured provider;
  unknown explicit slash commands do not silently become chat requests.
- Mobile UI uses clearer Spanish text, larger typography, quiet graphite surfaces,
  mint accents, permission indicators and a searchable command selector. Object,
  array, boolean and numeric inputs retain their types. No new runtime dependency.
- Work results are called verified only when the executor reports successful
  postconditions. Uncertain operations remain tracked and are never resent by polling.

Android is independently versioned **0.2.1-companion / versionCode 22**. The APK
remains a local debug artifact. A physical Android was unavailable during this
revision; camera scanning, installation and phone-to-PC physical acceptance remain
pending. Browser fixtures do not establish those results.

Internet relay, iOS, mobile screen capture for Magic Pen and complete mobile file
upload/converter workflows remain outside this revision. Registered desktop
commands are available according to their individual prerequisites and PC approvals;
the catalog does not prove every tool has been physically exercised.

This combined release preserves the Piper voice studio and routing introduced in Windows 0.22.15.

A missing or temporarily unavailable delivery receipt no longer marks the whole
PC disconnected. The phone can discard local tracking after an explicit warning,
keeping its draft without resending the operation. Work permission is checked
again after preparation and before execution; revocation cancels the prepared
operation instead of dispatching it.

Final Windows installation and 11 installed companion checks passed. Active voice
text now has 10.38:1 measured contrast. CarlFM and Ald each completed two playback
cycles using the same packaged backend; physical speaker/microphone acceptance
remains separate. The recovery utility preserves private data and the previous
installation while omitting historical backups and reproducible dependency caches.
