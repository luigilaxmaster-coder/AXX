# Axx 0.22.4

## Comandos por aplicación y ampliación revisada

- Catálogo de perfiles con instrucciones y acciones de navegador, comunicación,
  multimedia, Office, desarrollo, diseño y utilidades. Consulta
  [APPLICATION-COMMANDS.md](../APPLICATION-COMMANDS.md).
- Inventario real de Windows, apertura por ID único, ventanas ligadas a proceso,
  foco, inspección y cierre normal. Varias ventanas requieren HWND/PID explícitos.
- Navegación declarada en perfiles, observación UIA y permisos del ejecutor
  existente. Los atajos entregados conservan efecto desconocido sin confirmación.
- El taller genera código puro, ejecuta sus vectores de prueba, solicita revisión
  y registra sólo la versión aprobada. Revocar impide ejecutar preparaciones
  pendientes; reiniciar reconstruye las versiones activas. Los procedimientos
  reutilizan los adaptadores existentes. Integraciones generales permanecen como
  propuestas exportables para revisión técnica.
- Entrada Windows por AnythingMCP opcional, sin segundo ejecutor ni reintentos
  de efectos. Configuración, claves DPAPI, auditoría correlacionada y estado en
  Ajustes. Consulta [MCP-LOCAL.md](../MCP-LOCAL.md).

## Comprobación

- Suite completa: **656 pruebas**, correcta, con **13 omitidas** por requisitos
  de entorno; **4 pruebas de interfaz** y **16 de publicación** correctas.
- Instalación Windows x64 comprobada: versión, binarios, 36 avisos de licencia,
  backend autenticado y superficie nativa visible. El instalador tiene SHA256
  `295f3c0bc95407b093d168aeecce97c0f9f4a6134cf624c1bcf510489f161578`.
- Gateway instalado: **35 comprobaciones correctas**. Movimiento físico de
  **12 píxeles** y restauración exacta, tolerancia cero; cancelación en **62 ms**
  con el gateway pausado, sin ejecutar entrada nativa. Recuperación comprobada;
  las cinco operaciones exitosas tienen una sola invocación auditada cada una.
  Reutilizar una operación no produjo otra llamada al gateway.
- Chrome con perfil temporal propio: navegación mediante Axx y el gateway,
  postcondiciones correctas y **exactamente un GET independiente** a la página
  local de prueba. Limpieza completa. La lectura de dirección conserva
  `scheme_verified=false` y `content_verified=false` cuando Chrome oculta el
  esquema: no acredita TLS ni todo el contenido de una página.
- Generación real con `gpt-6.1-sol` y con el modelo seleccionado `gpt-6-sol`,
  sin fallback. Una misma propuesta avanzó a revisiones 2 y 3 con fuente distinta;
  cada revisión pasó sus **2/2 pruebas puras**. La última permanece como borrador
  pendiente de aprobación, sin activar ni ejecutar comandos.
- Observación nativa del catálogo, taller y cuerpo 3D. El taller recupera la
  consulta al abrir Comandos y muestra las revisiones guardadas después del
  arranque. El inventario observado contiene 200 accesos, no 200 integraciones
  completamente validadas.

Recibos privados: `build/release-0.22.4-delivery/`. Los verificadores reproducibles
son `verify-native-gateway.py`, `verify-application-navigation.py` y
`verify-generated-workshop.py` en `scripts/`. Las pruebas omitidas incluyen
Office, Blender, OCR, otros fixtures de navegador y creación de enlaces
simbólicos; no se promueven a resultados nativos aprobados.

## Requisitos y límites

Windows, aplicaciones instaladas y controles de accesibilidad compatibles.
Navegación CDP, cuentas de mensajería, Spotify Web API, control remoto TeamViewer,
OBS y Office requieren sus propias conexiones o componentes. Una instrucción
documental no los instala ni autentica. El código generado activable no accede
a archivos, red, procesos, Python general ni credenciales. La interfaz 3D y los
datos privados existentes se conservan. Android no cambia en esta entrega.
AnythingMCP debe estar activo; su inicio y la reconfiguración si cambia la red WSL
se describen en la guía del gateway. No se añade arranque automático de Windows.
