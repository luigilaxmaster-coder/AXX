# Axx 0.22.28

Discreto, Copiloto and Full share the existing assistant, SQLite journal, command executor and resident scheduler. The default remains Discreto. Explicit commands retain their existing approval and verification rules.

- After an approved file creation, Copiloto can propose a separate read/SHA-256 verification. Full can run that verification with a permission already bound to the task, artifact folder and validity period. Neither mode claims visual or semantic correctness from a hash.
- Profiles, exclusions, cooldown, attention limits and retention persist. Proposals bind the exact plan, file identity and content hash. Revocation, downgrade, Stop, rejection, expiry and interrupted receipts are rechecked before dispatch; uncertain effects are not repeated.
- Existing paused plans can be prepared for reviewed resumption. A recurring procedure needs three compatible verified occurrences in the same task; its preparation uses the existing SkillMemory and ActionLearning. Folder-conditioned preparation abstains until every destination can be resolved.
- Existing durable plans expose mission objectives, scope, verified/pending steps, blockers, budgets and stop conditions. Their original evaluator and receipts determine completion. Acceptance and usefulness remain separate.
- Actor, origin, causation and technical outcome are recorded separately. Axx initiatives do not become evidence of human habits. Forgetting excludes the old evidence from future anticipation; hashed causal tombstones survive proposal retention.
- Compact avatar cards provide the observed state, a review action, intervention and optional evidence under “¿Por qué?”. Busy voice/input contexts defer interruption. Protected avatar, radial and mobile styles are preserved.
- The supplied reasoning library adds 28 documentary references, preserving all 7,566 prior records. References retain source hashes, revision and limitations; existing bounded retrieval can select them, and none grants execution or installs an agent framework.
- The recovery button restores the hidden avatar before summoning it. Windows additionally registers the displayed Ctrl+Alt+Space shortcut, retains Alt+Shift+A, and reports a fallback if the new shortcut is occupied.

## Validation

Source, companion and installed acceptance receipts are recorded separately during delivery. A browser fixture is not native input evidence. The native anticipation test uses trial chats/files and restores the user's context; it does not certify whole-desktop isolation.

## Scope and remaining gates

This is the first integrated anticipation delivery. Continuous/adaptive screen, app, microphone and clipboard observation, broad autonomous desktop effects, cross-mission event dependencies, general speculative previews/undo, natural-language memory administration and new distributed execution are not enabled by these profiles. Existing demonstration and mobile integrations retain their current boundaries.

M15 remains open; R02 is not promoted into execution evidence. Full does not grant physical input, disclosure, transfers, deletion, installation or purchases. No new model or runtime dependency was introduced. Android remains independently versioned at 0.2.7, code 28; no new APK or physical-phone claim is part of this desktop delivery.

The final installer retains the existing official Whisper Tiny ASR resource and excludes the unused Silero VAD model; Axx's ASR explicitly uses `vad_filter=False`. Public upload requires an explicit exception for the official ASR weights to the repository's model-weight publication rule. Local build/installation and public publication are distinct delivery states. The actual final archive and ASR checks must confirm this packaging boundary.
