# Axx 0.22.37 — Spatial Intelligence and Magic Pen

## Cambios

- Magic Pen mantiene la pregunta visible mientras lees respuestas largas; las respuestas visuales muestran pasos, diagramas, procedencia y el nivel real de fidelidad.
- Canvas espacial crea escenas locales con componentes declarativos y seguros. La cámara, el aislamiento, la visibilidad, la separación de piezas y la navegación por pasos se controlan en el panel sin pedir una llamada al modelo por cada gesto.
- La sesión conserva selección, objeto activo, conversación, cámara y estado de vista al editar una escena. Three.js se incluye localmente; si WebGL no está disponible, Axx muestra los componentes y explica el estado.
- Se puede elegir explícitamente ChatGPT/Codex o un modelo Claude API ya configurado. El esfuerzo se limita a los niveles anunciados por cada modelo; no hay cambio silencioso de proveedor. La verificación externa se inicia a petición del usuario.
- El panel Magic Pen conserva voz, narración por pasos y la guía UIA existente. La guía señala controles y verifica postcondiciones; no los acciona automáticamente.
- Codex recibe un esquema JSON estricto que declara todas las propiedades, conserva los campos opcionales mediante `null` y normaliza esos marcadores antes de la validación cerrada de Axx. Claude conserva su esquema previo.
- La comprobación del proveedor muestra estados de progreso, éxito y error en una tarjeta compacta; el diagnóstico técnico queda plegado y se representa como texto seguro.
- Telegram admite solicitudes privadas `/voz <pregunta>` para devolver una nota hablada con la voz local seleccionada, si el permiso `voice_notes` está concedido. No transcribe notas de voz entrantes ni habilita acciones de PC.

## Límites y preparación

- La escena de motor incluida es conceptual y se limita a cuatro piezas. No produce CAD, dimensiones medidas, física ni geometría de ingeniería.
- La salida estructurada y el transporte están cubiertos por pruebas. La respuesta visual real de GPT‑6.1 Sol y de Claude API no se contó como verificada en esta entrega; se conservan las conexiones y autorizaciones de coste del usuario.
- El verificador de instalación acredita el proceso nativo y el backend. La aceptación visual/física final de Magic Pen en Windows, DPI, varios monitores, micrófono, WebGL real y una sesión Telegram con audio requiere observación nativa separada.
- No se incluyen muestras de voz, pesos de modelos, audios de entrenamiento ni datos/runtime privados.
