# Axx 0.22.37 — Spatial Intelligence and Magic Pen

## Cambios

- Magic Pen mantiene la pregunta visible mientras lees respuestas largas; las respuestas visuales muestran pasos, diagramas, procedencia y el nivel real de fidelidad.
- Canvas espacial crea escenas locales con componentes declarativos y seguros. La figura aparece centrada sobre el escritorio, sin recuadro ni fondo, y se desplaza arrastrando su asa. Arrastrar gira, Mayús+arrastrar o el botón derecho desplaza la vista, y la rueda o teclado cambian el zoom. La cámara, el aislamiento, la visibilidad, la separación de piezas y la navegación por pasos se controlan localmente sin pedir una llamada al modelo por cada gesto.
- El motor conceptual usa cilindro abierto con aletas, pistón con anillos, biela con ojos y cigüeñal con apoyos; acabados distintos para retenes, pasadores y apoyos, iluminación de estudio y una vista mayor facilitan distinguir cada pieza. Las cuatro piezas siguen siendo conceptuales.
- El visor nombra piezas al pasar el puntero y permite seleccionarlas con clic o lista accesible; una tarjeta muestra la función conceptual, el paso asociado y su procedencia, con controles locales para aislar, ocultar o separar la pieza. Si el panel estaba oculto, seleccionar una pieza vuelve a mostrar su explicación.
- Las piezas muestran etiquetas proyectadas en el modelo que abren su explicación; las carcasas genéricas tienen bordes suavizados y el motor abre en vista completa con aletas menos invasivas. «Más detalle» pide una nueva versión técnica sobre la misma captura. Las preguntas del chat pueden ajustar tamaño, posición, color o explicación de la pieza seleccionada mediante el patch validado.
- Al decir «me gusta este modelo» o pulsar «Guardar estilo», Axx guarda localmente la paleta y el número de piezas como referencia para futuros modelos 3D. «Estilo guardado» permite quitarla. La preferencia no incluye capturas, código, medidas ni geometría arbitraria.
- La sesión conserva selección, objeto activo, conversación, cámara y estado de vista al editar una escena. Three.js se incluye localmente; si WebGL no está disponible, Axx muestra los componentes y explica el estado.
- Se puede elegir explícitamente ChatGPT/Codex o un modelo Claude API ya configurado. El esfuerzo se limita a los niveles anunciados por cada modelo; no hay cambio silencioso de proveedor. La verificación externa se inicia a petición del usuario.
- Los modelos visuales configurados por OpenAI Chat Completions, como Gemma en Ollama, pueden generar explicaciones, señalamientos y diagramas 2D con el contrato visual reducido. El control 3D se habilita únicamente para rutas Codex o Anthropic visuales; cambiar de modelo siempre es explícito.
- El panel de pregunta indica la capacidad del modelo seleccionado y ofrece acciones de Señalar, Diagrama y Modelo 3D con el control no disponible desactivado. Las marcas se anclan a la selección y permanecen visibles al pausar la narración.
- El panel Magic Pen conserva voz, narración por pasos y la guía UIA existente. La guía señala controles y verifica postcondiciones; no los acciona automáticamente.
- Codex recibe un esquema JSON estricto que declara todas las propiedades, conserva los campos opcionales mediante `null` y normaliza esos marcadores antes de la validación cerrada de Axx. Claude conserva su esquema previo.
- La respuesta de Codex para una captura temporal se entrega desde la ejecución activa; el historial persistido sigue ocultando su contenido para proteger la captura.
- La comprobación del proveedor muestra estados de progreso, éxito y error en una tarjeta compacta; el diagnóstico técnico queda plegado y se representa como texto seguro.
- Telegram admite solicitudes privadas `/voz <pregunta>` para devolver una nota hablada con la voz local seleccionada, si el permiso `voice_notes` está concedido. No transcribe notas de voz entrantes ni habilita acciones de PC.

## Límites y preparación

- La escena de motor incluida es conceptual y se limita a cuatro piezas. No produce CAD, dimensiones medidas, física ni geometría de ingeniería.
- La preferencia guardada orienta al proveedor sobre paleta y nivel de detalle; no garantiza que otra clase de objeto admita la misma composición. Una selección plana o de interfaz debe explicarse con diagrama 2D, aunque el usuario pulse Modelo 3D.
- Una instalación previa de 0.22.37 con captura sintética produjo un señalamiento visible del pistón con `axxx3 / gemma4:31b`, un diagrama de dos nodos con esa misma conexión y una escena conceptual de cuatro piezas con `@codex / gpt-6.1-sol`. El resultado está en `build/release-0.22.37-gemma-final/installed-spatial-proof.json`. La superficie flotante de esta revisión requiere una nueva prueba nativa antes de publicarse. La identidad del modelo respondedor de la ruta Ollama no quedó atestiguada fuera de la ruta configurada.
- Claude con imagen, DPI y varios monitores, micrófono real y una sesión Telegram con audio requieren pruebas independientes antes de declararse aceptados.
- No se incluyen muestras de voz, pesos de modelos, audios de entrenamiento ni datos/runtime privados.
