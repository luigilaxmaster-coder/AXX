# Axx 0.20.22 — Windows application control

This test release adds typed application and window actions to the existing command registry and executor.

## Delivered

- Lists Start Menu applications and visible top-level windows with distinct detected, observed, focused, and action-ready states.
- Opens Notepad and Explorer through Windows; a follow-up action requires a matching foreground window and a fresh HWND/PID observation.
- Inspects bounded UI Automation trees in a separate PowerShell MTA worker. Control selectors are hashes of ephemeral UIA RuntimeIds and are resolved again before each write.
- Supports approved `ValuePattern` writes with a SHA-256 and length readback. UIA timeouts and cancellation stop the worker and leave the operation requiring reconciliation.
- Preserves the existing phone/Windows input owner. The new semantic UIA path does not inject a competing mouse or keyboard stream. Physical `SendInput`/remote cursor actions are not added by this release.
- Excludes HWND/UIA selectors and write text from learned procedures; procedures are invalidated when their command contract or adapter version changes.

## Windows observations

- Notepad opened and reached a verified foreground state. A newly created empty temporary document exposed an observed UIA Document control. The approved typed write completed with readback evidence, then a second approved write cleared the temporary buffer.
- Explorer was opened and its existing UIA tree was observed. Windows kept Notepad in the foreground, and the attempted focus change was denied by Windows; Axx reported `ready_for_action: false`. No Explorer action was dispatched.
- This is a first acceptance slice, not universal application coverage. Explorer focus and a verified Explorer action remain pending on this machine. Controls without a unique observed selector and writable `ValuePattern` remain unavailable.

## Validation

See `docs/CONTROL-DE-APLICACIONES.md` for commands and limits. UI-contract tests do not prove voice recognition. Android versioning and hardware acceptance are unchanged.
