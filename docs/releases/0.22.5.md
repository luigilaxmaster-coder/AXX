# Axx 0.22.5

Computer Use añade un ciclo visual en el chat de Axx: autorización explícita de
una ventana, imágenes reales enviadas a Codex, gestos mediante el broker nativo y
comprobación posterior. Incluye indicador de sesión, parada, tickets de un solo
uso y bloqueo de gestos tras un efecto incierto. Las imágenes no se guardan en el
journal. Véase `docs/COMPUTER-USE.md` para uso y límites de compatibilidad.

El objetivo original permanece vinculado al Taller cuando falta una transformación. Axx puede generar una función pura, ejecutar sus pruebas, presentar la revisión y preparar de nuevo la misma tarea al activarla. El planificador descubre las transformaciones activas y puede reutilizarlas con otros datos; los archivos de texto declarados se verifican contra un contrato independiente del candidato.

Codex separa planificación y generación de código, manteniendo modelo exacto, herramientas directas deshabilitadas y ausencia de fallback de pago. Se conservan journal, aprobaciones, cancelación y referencias de versiones. Las revisiones reparadas necesitan un binding compatible explícito.

Las regresiones de Chrome distinguen navegación, búsqueda, reproducción y movimiento del cursor. Las continuaciones musicales se limitan al mismo chat y diez minutos. La navegación inspecciona controles de dirección acotados; el reproductor exige muestras de avance para confirmar éxito.

Validación de Windows instalado: Axx 0.22.5 envió dos imágenes de una ventana
Win32 de prueba a Codex, ejecutó un único clic por coordenadas y comprobó su
resultado mediante accesibilidad. La lectura independiente de Windows coincidió;
se verificó la revocación. La prueba se realizó con escala de pantalla 125%.
El modelo también construyó una transformación pura, pasó cinco pruebas, conservó
el objetivo al activarla y creó dos archivos con lotes distintos reutilizando la
misma versión. Ambos contenidos y SHA-256 se leyeron independientemente.

Las pruebas de backend, transporte, interfaz y Rust pasaron. Los recibos privados
de compilación e instalación verifican versión, binarios, servicio autenticado y
ventana visible. La creación de adaptadores CAD/Office arbitrarios y la cobertura
universal de visión siguen pendientes; las propuestas de código no se importan
automáticamente. La reproducción nativa en YouTube no forma parte de esta
aceptación. Véase `docs/GOAL-CYCLE.md`.
