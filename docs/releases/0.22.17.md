# Axx Desktop 0.22.17

## Voice

- Added **Axxmorcito** to the shared voice selector and Voice Studio. It uses
  private local references for Spanish and English, with independent audio
  cache keys. New profiles prefer it when its Spanish reference is installed;
  saved voice choices are preserved.
- Restyled the active voice, choices, language/model controls, help text and
  speed control with legible contrast in the dark voice panel.
- The three user recordings remain private. The Windows installer contains no
  user sample, generated preview or trained weight. See
  [Axxmorcito setup](../voice/axxmorcito.md).

## Measured on this PC

With the current ONNX CPU model warmed, MOSS delivered the first PCM packet in
609 ms (Spanish) and 453 ms (English). Full synthesis took 4.70 s and 5.16 s,
respectively. Repeating the identical text reused the local cache in 31 ms.
The initial model and reference warmup took 13.84 s. A local ASR check recovered
the short English sentence exactly; it changed one Spanish verb while retaining
the meaning. These figures measure only the synthesis service, not microphone,
transcription, model response, speaker playback or end-to-end conversation.

## Validation and limits

Python speech tests and the synthetic native voice UI test passed. Physical
speaker quality and the installed 0.22.17 app still require acceptance. The
official MOSS fine-tuning script requires CUDA; this PC has no CUDA device, so
the voice uses reference-conditioned inference, without fine-tuned weights.
