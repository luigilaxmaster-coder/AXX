# Axx 0.22.0 — tareas de escritorio verificables

Esta versión incorpora tareas acotadas y adaptadores verificables sobre el ejecutor existente. La tabla de entrega distingue pruebas de código, empaquetado e instalación.

El chat prepara tareas de hasta ocho pasos con `/tarea`, muestra sus recibos y permite pausar al terminar el paso activo, retomar con contexto revalidado y detener la ejecución. Los resultados verificados pueden alimentar parámetros de pasos siguientes mediante referencias tipadas. Observaciones truncadas, identidades caducadas y efectos inciertos impiden continuar o repetir mutaciones sin comprobación. No se aprenden selectores efímeros como habilidades permanentes.

La observación de Windows incorpora UIA, identidad de proceso, foco, geometría y monitores. Los adaptadores exponen estados accesibles, lectura de tablas, geometría de ventana y entrada mediante el broker compartido. Una entrada genérica entregada no se etiqueta como efecto de aplicación verificado. Las propuestas visuales necesitan proveedor configurado e imagen autorizada; no ejecutan automáticamente el punto sugerido.

Los nuevos flujos de archivos conservan originales, crean destinos exclusivos y comprueban copias, manifiesto SHA256 y ZIP. El puente de navegador requiere un perfil CDP preparado explícitamente en loopback; inspecciona y navega una pestaña y documento concretos. No conecta el perfil habitual automáticamente ni completa todavía el flujo descarga PDF → visor.

Word crea una copia DOCX con texto añadido y PDF legible; exige Word cerrado y rechaza contenido activo o referencias externas. Excel importa CSV con separador y columna numérica declarados, mantiene texto potencialmente interpretable como fórmula inerte, calcula SUM y verifica el XLSX reabierto. Ambos usan instancias privadas supervisadas y preservan los originales. Un bloqueo anterior a verificar la identidad de Office conserva incertidumbre sobre el cierre; nunca justifica terminar una sesión ajena.

El ejecutor de procesos acepta una petición explícita de terminal, un `.exe`, argumentos revisados y cwd concreto. Exit code cero no equivale a una postcondición de aplicación. El control genérico no sustituye puentes semánticos de AutoCAD, Revit, SketchUp, Photoshop, OBS o Blender.

Los doce casos del documento de arquitectura tienen una matriz explícita en [COMPUTER-USE.md](../COMPUTER-USE.md). Word y Excel tienen aceptación nativa sobre fixtures; los flujos CAD/BIM y otras aplicaciones especializadas permanecen pendientes. No se afirma que todo el escritorio esté cubierto.

La inferencia real del proveedor local sigue pendiente: el servicio Ollama estaba detenido y la revisión automática rechazó su inicio. Los ensayos de planificación usaron transporte de modelo controlado. No se subieron capturas para probar grounding externo ni se descargaron modelos. La prueba física de micrófono y las combinaciones adicionales de DPI/monitores no se repitieron en esta entrega.

Los cambios preservan preferencias, credenciales, interfaz 3D y archivos previos. Las salidas nuevas se crean dentro del espacio autorizado y los resultados parciales se conservan con evidencia. Android no cambia. Dependencia adicional del navegador: `websocket-client==1.9.2`; no se descargan modelos, perfiles personales ni extensiones.
