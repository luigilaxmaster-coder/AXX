# Axx 0.22.18 · Local voice playback and phrase bank

- Added per-voice playback controls for MOSS and Piper: bass, presence, air, level and pitch, with four presets. By default the selected personality subtly adjusts sound and pace; a manual voice setting overrides that automatic treatment. New Juguetona and Psicópata · ficción +17 styles affect wording and delivery. They can offer occasional harmless, local-only surprises while the chat is visible and idle; they never execute an action. Pitch changes playback duration slightly; source recordings remain untouched.
- Added a private, reference-aware MOSS phrase bank and a 250-entry Spanish/English phrase catalog. Plain spoken greetings, thanks and farewells can use prepared speech; slower model turns can play one contextual lead after 1.2 seconds. The setting can be disabled in Voice Studio. No loading sound is enabled.
- Added an offline CPU fine-tuning path for MOSS-TTS-Nano. The experimental Axxmorcito checkpoint and all voice samples remain in local app data. The trained checkpoint is **not** selected as the default: held-out Spanish recognition improved, but speaker similarity changed minimally and English similarity fell. Dynamic speech continues through the existing MOSS ONNX engine.
- Private phrase audio is generated locally with `python scripts/build-voice-phrase-bank.py`; the app never bundles or publishes user recordings, audio bank files or model weights. Cache keys include the reference voice and engine signature, so changed inputs cannot replay the old voice.

## Validation boundary

Syntax, backend speech unit tests, browser voice controls and streamed PCM playback were checked before packaging. The phrase bank generation is a separate local step; its count and WAV validity must be checked on the installed machine. Cached first PCM and full microphone-to-speaker latency are different measurements. Physical listening, microphone timing and speaker similarity still require user acceptance on the target Windows PC.
