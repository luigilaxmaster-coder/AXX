# Axx 0.21.3 — control de aplicaciones y procedimientos verificados

Integra las acciones Windows con el dueño existente de entrada, sin reemplazar la interfaz 3D. El controlador local conserva prioridad y cancelación; el worker UI Automation funciona en COM MTA separado. El estado diferencia entrada física, teléfono y automatización Axx.

El enfoque restaura ventanas minimizadas y comprueba foreground e identidad antes de actuar. Explorador abre carpetas locales mediante un adaptador tipado y verifica ubicación y foco. Notepad resuelve el documento por título exacto observado, escribe solo en un editor accesible único tras aprobación y compara longitud/SHA256. No guarda archivos ni cierra pestañas. El panel existente incorpora enfoque, escritura revisada y apertura de carpetas.

Los flujos exitosos pueden guardarse como procedimientos parametrizados mediante el recibo del ejecutor. Al repetirlos se resuelven ventanas y controles actuales y se conservan aprobaciones, cancelación y pasos ya consumados. Un timeout de escritura conserva estado incierto; su efecto se puede reconciliar por lectura, sin repetirlo.

Las pruebas y aceptación instalada se registrarán tras verificar el paquete final. No se afirma compatibilidad universal. Documentos ambiguos, controles sin ValuePattern, ventanas elevadas o proveedores UIA bloqueados pueden requerir intervención. Android mantiene su versión.
