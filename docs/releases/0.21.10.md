# Axx 0.21.10 — controles observados y CMD por voz

## Cambios

- «Escribe en ChatGPT [texto]» o «escribe [texto] en Antigravity» identifica un único campo editable visible mediante Windows UI Automation, prepara el texto y exige aprobación. Comprueba el valor escrito; no envía el mensaje.
- «Haz clic en [botón] en ChatGPT/Antigravity/Chrome/Spotify» observa una ventana y un botón con nombre exacto, exige aprobación y comprueba la entrega de la pulsación. El efecto posterior dentro de la aplicación queda sin verificar.
- El descubrimiento de capacidades ofrece la acción `press` cuando observa botones utilizables; conserva la identidad de ventana, proceso y control.
- «Ejecuta en CMD: [comando]» puede dictarse. El comando reconocido se muestra para revisión y requiere pulsar Aprobar en Axx; no se ejecuta al oírlo. PowerShell sigue requiriendo texto escrito.
- «Abre ChatGPT» prefiere la aplicación instalada cuando Windows identifica una única entrada; si no está instalada, abre el sitio web.

## Validación

- 88 pruebas dirigidas de backend, descubrimiento, CMD, voz y Axx Connect; 27 pruebas de contrato de la interfaz de comandos.
- La ventana real de ChatGPT expuso un único campo editable visible y el botón «Nuevo chat»; ambas frases se resolvieron a acciones tipadas sin escribir ni pulsar durante esta prueba.
- Pendiente: ejecución física aprobada de escribir/pulsar en ChatGPT y Antigravity, micrófono real y latencia de voz de extremo a extremo. El comando CMD sigue ejecutándose en segundo plano con salida y código de retorno; no se abre una consola visible.
