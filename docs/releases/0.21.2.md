# Axx 0.21.2 — aprobaciones claras y lectura de páginas y aplicaciones

Incluye también la actualización de Magic Pen 0.21.1: selección sobre el escritorio, widget junto a la región, tinta editable y recuperación del selector al cambiar de pantalla.

La aprobación muestra primero pasos numerados, archivos, contenido y destinos. Los comandos exactos siguen disponibles en un desplegable. Los pasos completados de una tarea reparada se identifican como conservados; el botón cuenta solo los pendientes. Se mantienen la aprobación vinculada a parámetros, la cancelación y la recuperación por operación.

«Leer páginas y aplicaciones» permite elegir una ventana y aprobar la lectura de su contenido accesible. También reconoce `lee la ventana Título`, `lee la página Título` y `lee YouTube`. Lee texto y direcciones expuestas por Windows UI Automation, sin depender de una lista de sitios. En navegadores compatibles identifica un único documento correspondiente a la ventana actual; rechaza páginas ambiguas en vez de mezclar pestañas.

Los enlaces observados pueden abrirse desde el panel. En resultados visibles de YouTube, `abre el primer video` usa la dirección observada y su ID real, sin inferirlos del título. Las lecturas caducan para apertura a los 60 segundos. El contenido permanece local hasta que el usuario decide adjuntarlo a su próxima pregunta al modelo.

Comprobaciones: 165 pruebas de backend, 22 de acciones, 20 contratos de interfaz de comandos, contratos del lector, aprobación y repetición idempotente del lector mediante el ejecutor central, y flujo de aprendizaje con HTML completo/backend fuente/archivos reales. Este último usa un modelo de prueba local y no mide calidad del razonamiento. Lectura real de títulos y URLs de YouTube y de una página pública de IANA; la segunda comprobación confirmó aislamiento frente a documentos de pestañas inactivas.

Límites: no es acceso universal al DOM, ni OCR de interfaces dibujadas. La cobertura depende de accesibilidad; documentos protegidos, controles no expuestos, ventanas elevadas y páginas ambiguas pueden requerir intervención. No se certifica compatibilidad con todas las aplicaciones o páginas. Android no cambia.
