# Axx 0.22.15 — Voces Piper y apartado de voz

- Nuevo apartado **Voces de Axx** accesible desde el chat y el catálogo de
  asistencia. Presenta cuatro opciones visuales, indica cuál está en uso y
  deshabilita las voces que faltan. El chat conserva selección y prueba breves;
  idioma, modelo para respuestas habladas y velocidad están en el apartado
  completo.
- El mismo URI de voz se usa en chat, lector, dictado y Voz en vivo. Xxx default,
  Windows y la preferencia previa permanecen disponibles.
- Piper local admite `es_ES-carlfm-x_low` y `es_MX-ald-medium`. El modelo se
  prepara fuera del hilo de la interfaz y queda residente; la respuesta usa el
  lector y los controles existentes de pausa, cancelación y prueba.
- Los modelos Piper y el runtime se instalan solo en datos privados del usuario
  con `python scripts/setup-piper-voices.py all`; no se incluyen en el
  instalador ni en Git. Una voz no instalada aparece deshabilitada.

En este equipo se verificaron ambos modelos con WAV PCM real. En una frase
aislada, la segunda síntesis tras la preparación tardó 390 ms para CarlFM y
375 ms para Ald. La primera preparación tardó 9,6 s y 7,7 s respectivamente.
Son mediciones locales de síntesis; no incluyen micrófono, ASR, modelo de chat,
Web Audio ni altavoces. Los pasos y las licencias están en
[`docs/voice/piper.md`](../voice/piper.md).

Validaciones de código: `backend.tests.test_piper_tts`,
`backend.tests.test_delivery_contract`, `backend.tests.test_moss_stream`,
`1.AXX/scripts/test-dictation-runtime.cjs`, `test-desktop-frontend.cjs` y
`scripts/validate_js.js`. El instalador 0.22.15 se instaló y el backend privado
generó WAV PCM autenticado con ambas voces (CarlFM 16 kHz, Ald 22,05 kHz).
En esa prueba local, la síntesis HTTP tardó 172 ms y 125 ms respectivamente;
son dos muestras breves, no una medición de conversación. La audición física y
el panel dentro de la ventana instalada aún requieren aceptación aparte.
