# Axx 0.20.20 — Spanish speech preparation and streamed pauses

The custom voice reader now sends its selected language to MOSS. Spanish speech
preserves accents, ñ, opening questions and exclamations; it expands common
abbreviations, isolated cardinal numbers up to 9999 and integer percentages.
Versions, dates, network addresses, IDs and ambiguous decimal formats are left
unchanged. English does not receive Spanish number or abbreviation expansions.
Displayed text is unchanged.

Latin speech no longer receives the upstream normalizer's Chinese terminal and
repeated punctuation. Inter-block pauses now reach streaming playback as well
as the completed WAV; previously the streamed voice omitted those pauses.
The same reference samples, voice IDs, sampling parameters and pitch are kept.
Reference cropping and alternate spellings were compared and rejected because
they did not improve all four voices consistently.

On the development PC (i7-1255U, four CPU threads), the four prepared voices
produced their first PCM chunk in **375–500 ms** for the Spanish test sentence
containing a title, a cardinal number and a percentage. These are synthesis
measurements, not end-to-end chat latency or guarantees for other hardware.
A longer Spanish reading verified that streamed PCM and the completed WAV
contain the same number of samples, including pauses between token blocks.

Validation: 17 focused backend tests; real Web Audio checks for language
forwarding, progressive playback, pause/resume, ordered phrases and cancellation.
The installed Windows 0.20.20 app completed twelve readings: a Spanish numerical
sentence, an everyday Spanish question and an English greeting for each voice.
Playback began in **664–1127 ms**, with **zero buffer underruns** in all twelve.
Interrupting a reading and starting another took **700 ms**, also without an
underrun. Native Web Audio timing and completion were observed; there was no
external speaker/microphone recording or human listening evaluation.
Installed artifact hashes and native startup/window visibility passed verification.
The native screenshot retained the existing avatar interface. Twelve release
workflow tests also passed.
Review was performed by the implementing agent, without an independent reviewer.

Quality limits: local tiny Whisper comparisons recognized the expanded Spanish
percentages more consistently, but still produced errors in names and ordinary
words. ASR is not a listening evaluation and does not certify naturalness or
speaker similarity. Three of the four private reference recordings are in
English; cross-language accent and articulation remain model/reference limits.
No model weights were trained or replaced. The [upstream model](https://github.com/OpenMOSS/MOSS-TTS-Nano)
provides the multilingual synthesis and reference-voice conditioning.

The optional voices still require the user's local MOSS runtime and samples.
No samples, transcripts or model weights are published. The Windows installer
is unsigned; phone trust and Android versions are unchanged.
