# Axx 0.22.33 — Telegram, compatibilidad y licencia MIT

- Integra las secuencias de Telegram: una tarjeta y aprobación nueva por paso; sólo se prepara el siguiente tras un recibo comprobado. Denegar, incertidumbre, revocación o reinicio detienen la continuación.
- Las URLs seguidas de «ponme este vídeo» conservan su URL exacta. La búsqueda de reproducción usa la ruta existente y acotada de Chrome; abrir o buscar no acredita reproducción.
- El olvido coordinado depura las secuencias, respuestas operativas y confirmaciones de los contextos afectados, incluidos los derivados. Conserva IDs, otras sesiones y reintento durable. Una respuesta tardía no restaura la secuencia.
- Las referencias de habilidades incluyen la huella de entorno en la revisión aprobada. Se comprueba antes de ejecutar y por paso pendiente. Revalidar no aprueba planes anteriores; las ramas completadas conservan su identidad y sus efectos.
- La ruta de escenas Blender registra el SHA-256 del ejecutable desde el ledger. Mantiene el binario bajo custodia durante el despacho, con un handle independiente para cada contexto anidado y caducidad de las copias al cerrarlo y permite un ensayo manual con copia privada y destino nuevo. No se incorpora a permisos de iniciativa ni se abre M15.
- Una aplicación desconocida no se presenta como comprobada. El incidente permanece disponible para lectura manual y queda excluido de selección automática.
- Añade licencia MIT para el código original, metadatos de licencia y copia del texto en los paquetes. Se conservan las licencias y avisos de terceros.
- Reorganiza el README con navegación, perfiles, acceso a guías e historial sincronizado automáticamente. Fuente candidata y descarga publicada se muestran por separado; las notas y enlaces se actualizan con `release.py sync`.

## Versiones y aceptación

Fuente coordinada: Windows **0.22.33**, Android **0.2.14/code35**. Conserva `/v1`, identidad Android, firma, pairing y versiones independientes. La nueva versión Android incorpora el texto MIT y la procedencia de la fuente actual.

La fuente pasó 178 regresiones dirigidas, 24 pruebas del publicador y 15 del contrato de compatibilidad. El gate conjunto final pasó 111 pruebas de backend móvil (una omitida por plataforma), 58 de navegador y 8 del selector, conservando los hashes de diseño aprobados. El README se renderizó mediante GitHub GFM y su vista previa no desbordó a 1.280 y 390 píxeles.

Windows 0.22.33 está compilado e instalado: 199.414.443 bytes, SHA-256 `74ba2abb100a65fb06800f5d12bb09aaf8a6c9f8dd804154315a69aaaf0005ce`. Se comprobaron arranque autenticado, HTTP 401 sin token, superficie visible, 2.050 archivos del backend y texto MIT instalado. El respaldo verificó 9.804 archivos; se conservaron datos, 435 mensajes e identidad TLS, con una actualización de timestamp de conversación al arrancar. Aceptación nativa y publicación pendientes; la última descarga confirmada sigue siendo Windows 0.22.32. No se reutiliza la aceptación de otro binario.

La CI detectó una dependencia del fixture respecto de una instalación local de Blender. Se aislaron sus dos puntos de descubrimiento y ProgramFiles; las siete pruebas pasan sin depender de Blender instalado. La corrección sólo cambia pruebas; conserva los bytes y recibos del instalador.

Android 0.2.14/code35 está compilado y firmado: 7 pruebas JVM PASS, lint con 0 errores y 33 avisos, 22 assets canónicos y texto MIT comprobados dentro del APK. Conserva application ID y certificado de pruebas. SHA-256: `abb5695a54db51017ff00549e8c157964d7962a6131edcaefd101d76e879c77f`.

Android no está instalado ni aceptado físicamente: el usuario no puede conectar el teléfono ahora. La autorización ADB existente cubre instalación y metadatos, sin automatizar pulsaciones. No se publica un APK como físicamente aceptado.

## Límites preservados

Full conserva los permisos vigentes. `SOURCE_PLANNING_READY=False` y el bloqueo de aislamiento/M15 siguen activos. Desactivar Conservar contexto impide guardar o ejecutar derivados de pantalla, micrófono o portapapeles.

La primera huella de aplicación cubre el ejecutable de escenas Blender, con pruebas de metadatos y efectos simulados declarados. No acredita un render nativo, todas las DLLs/plugins ni la versión de Office, navegadores u otras aplicaciones. La equivalencia de rutas y el resto de pendientes permanecen en el [informe M1–M12](../anticipation/IMPLEMENTATION-STATUS.md).

No se incluyen modelos, muestras de voz ni estado de ejecución. Los datos y voces locales se conservan; los backups y recibos privados no se publican.
