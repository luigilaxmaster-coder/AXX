# Axx 0.21.8 — selección de modelos clara y comprobable

## Cambios

- El panel de modelos presenta tres rutas claras: Ollama en este equipo, ChatGPT con la sesión de Codex y otros modelos. Las conexiones manuales quedan en ajustes avanzados.
- Cambiar de pestaña o elegir un modelo del catálogo no altera el proveedor activo. ChatGPT solo pasa a ser el modelo en uso después de responder una pregunta de comprobación; un fallo conserva el modelo anterior.
- El panel muestra por separado el modelo guardado, la conexión y si una respuesta real fue comprobada. Los controles de Ollama permanecen en su propia ruta.
- La consulta de modelos de ChatGPT actualiza el estado y el catálogo sin iniciar una conexión inesperada.

## Validación

- Contratos de navegador: selección de proveedores, 36 verificaciones de Axx Connect y 29 verificaciones de frontend de escritorio.
- La prueba controlada confirma que una selección fallida conserva la ruta previa y que cambiar de pestaña no modifica el modelo activo.
- El instalador Windows pasó la comparación de archivos y el arranque nativo autenticado. En la aplicación instalada aparecieron 20 modelos de Ollama; cambiar de pestaña conservó la ruta activa y seleccionar ChatGPT no la modificó hasta que `gpt-6.1-sol` respondió la prueba. Se restauró la configuración anterior.
- Se observaron el panel instalado en temas oscuro y claro. El paquete publicado se comprueba por su hash de GitHub durante la publicación.
- No se midió la latencia de voz ni se ejecutó una prueba con micrófono físico en esta entrega.
