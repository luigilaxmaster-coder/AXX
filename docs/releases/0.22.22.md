# Axx 0.22.22 · Barra de comandos y modelos por API

- La conversación intenta reconectar al modelo guardado cuando su conexión se perdió. Respeta la desconexión explícita y la cancelación; no cambia de proveedor para ocultar un fallo.
- Las acciones nuevas se preparan como tareas revisables con el modelo seleccionado, también en ChatGPT. Los parámetros incompletos pasan al mismo planificador. Las aclaraciones conservan la selección de proveedor.
- El primer comando local no absorbe una secuencia como «abre Chrome y busca Faint en YouTube». Se conservan los planes ordenados, las aprobaciones y la parada ante resultados no comprobados.
- Las tareas sin un chat asociado usan una identidad estable válida para la inferencia por API, en lugar de enviar `null` y fallar antes de contactar al modelo.
- Por API muestra la conexión seleccionada y distingue configuración de respuesta comprobada. Los campos de conexión quedan visibles y agrupados; Probar respuesta usa únicamente una frase sintética y comprueba la ruta devuelta, sin enviar el historial.
- Un timeout de respuesta RPC retira únicamente el proceso Codex capturado; la siguiente petición puede iniciar otro. No reenvía automáticamente el mensaje ni convierte un resultado incierto en éxito. La conexión ChatGPT se comprueba al solicitarla, sin añadir una generación durante el arranque de Axx.

Validación de fuente: 33 casos de la biblioteca de comandos, pruebas de proveedores y barra rápida, 11 casos de aprendizaje y 17 casos HTTP de habilidades/comandos. Los fixtures no acreditan interacción nativa. En 0.22.21 instalada, la API existente respondió en 2,76 s y preparó dos consultas en 1,62 s con un chat válido; la prueba sin chat reveló y motivó la corrección de identidad.

La primera instalación 0.22.22 verificó hashes, registro, atajos, backend autenticado y configuración privada conservada. La API devolvió texto en 3,25 s y preparó dos consultas sin chat en 2,06 s. El ejecutor listado de ventanas completó sus postcondiciones en 10,66 s. Codex agotó thread/start; una reconexión explícita permitió planificar con gpt-6-luna en 10,28 s. Este fallo motivó añadir el retiro automático del proceso atascado, cubierto por 71 pruebas del proveedor (una omitida), con una segunda pasada completa aprobada tras un fallo temporal de temporización en la primera.

El paquete se regenera después de esa corrección; su instalación final, aceptación desde la barra nativa y publicación siguen pendientes. Los planes de prueba se cancelaron sin ejecutar sus pasos. El catálogo instalado tenía 69 comandos expuestos y 195 campos: sus esquemas pasaron la validación, lo que no acredita 69 efectos reales. Los comandos importados sin adaptador, los servicios sin credenciales válidas, las acciones sujetas a aprobación y las superficies protegidas conservan sus restricciones. No se garantiza control universal ni disponibilidad permanente de servicios externos. Android mantiene su versión independiente.
