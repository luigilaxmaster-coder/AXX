# Axx 0.22.22 · Barra de comandos y modelos por API

- La conversación intenta reconectar al modelo guardado cuando su conexión se perdió. Respeta la desconexión explícita y la cancelación; no cambia de proveedor para ocultar un fallo.
- Las acciones nuevas se preparan como tareas revisables con el modelo seleccionado, también en ChatGPT. Los parámetros incompletos pasan al mismo planificador. Las aclaraciones conservan la selección de proveedor.
- El primer comando local no absorbe una secuencia como «abre Chrome y busca Faint en YouTube». Se conservan los planes ordenados, las aprobaciones y la parada ante resultados no comprobados.
- Las tareas sin un chat asociado usan una identidad estable válida para la inferencia por API, en lugar de enviar `null` y fallar antes de contactar al modelo.
- Por API muestra la conexión seleccionada y distingue configuración de respuesta comprobada. Los campos de conexión quedan visibles y agrupados; Probar respuesta usa únicamente una frase sintética y comprueba la ruta devuelta, sin enviar el historial.
- Un timeout de respuesta RPC retira únicamente el proceso Codex capturado; la siguiente petición puede iniciar otro. No reenvía automáticamente el mensaje ni convierte un resultado incierto en éxito. La conexión ChatGPT se comprueba al solicitarla, sin añadir una generación durante el arranque de Axx.

Validación de fuente: 33 casos de la biblioteca de comandos, pruebas de proveedores y barra rápida, 11 casos de aprendizaje y 17 casos HTTP de habilidades/comandos. El proveedor Codex pasó 71 pruebas (una omitida); una segunda pasada completa aprobó después de un fallo temporal de temporización en la primera.

La instalación final 0.22.22 verificó hashes, registro, atajos, backend autenticado y cuatro archivos privados de configuración sin cambios. La API guardada axxx3 devolvió AXX_API_OK por la ruta configurada gemma4:31b en 1,25 s y preparó dos consultas sin chat en 1,73 s. Codex gpt-6-luna preparó el mismo plan en 12,88 s. Son pruebas de respuesta y planificación; esos planes se cancelaron sin ejecutar sus consultas. El listado de ventanas por el gateway tardó 3,17 s en caliente y 26,95 s al recuperar su contenedor detenido.

La entrada nativa del chat envió «lista mis ventanas» y completó la consulta con recibo asociado a su conversación. La barra pequeña también envió esa consulta: ejecución verificada, entrega background y respuesta compacta visible sin abrir el chat. La secuencia «abre YouTube y luego busca Faint de Linkin Park» enviada desde el chat preparó exactamente esos dos pasos. Con la autorización humana previa se ejecutó por la API local: ambos recibos confirmaron os_handoff, con el segundo paso iniciado después de finalizar el primero. Consultar resultado actualizó la interfaz nativa a succeeded sin repetir efectos.

La misma secuencia se repitió desde la barra pequeña instalada: widget compacto, Revisar acción, aprobación mediante teclado en el control nativo y dos pasos completados sin solapamiento. La UI confirmó «Pasos ejecutados y comprobados». En la captura de Axx se observó detrás la página de resultados de Faint en YouTube. La comprobación sigue limitada a abrir y buscar; no se pulsó reproducir. Los recibos privados quedan en build/release-0.22.22-final-ui y no se publican con el instalador.

El catálogo instalado auditado tenía 69 comandos expuestos y 195 campos: sus esquemas pasaron la validación, lo que no acredita 69 efectos reales. Los comandos importados sin adaptador, los servicios sin credenciales válidas, las acciones sujetas a aprobación y las superficies protegidas conservan sus restricciones. No se acredita reproducción del vídeo ni control universal o disponibilidad permanente de servicios externos. Android mantiene su versión independiente.
