# Axx 0.22.39 — Claude en Magic Pen, prueba de conexión aislada y fábrica de ensamblajes

## Cambios

- **Prueba de conexión de proveedores aislada de la memoria.** El botón «Comprobar respuesta» usa el nuevo endpoint autenticado `POST /axx-api/providers/probe`, que construye una solicitud interna fija (sin texto del cliente, herramientas, tareas ni memoria). La guarda de memoria de `/axx-api/chat` no cambia: un ID `connection-test-…` falsificado sigue rechazado tras olvidar memoria. Corrige el fallo previo de memoria atribuible.
- **Compatibilidad con Claude 5 verificada contra la API de Anthropic:**
  - `temperature` se omite para `claude-*-5+` (la API lo rechaza con HTTP 400).
  - El esquema de salida estructurada se envía sin `maxItems` ni `minItems > 1`, que Anthropic rechaza; los validadores de Axx conservan todos los límites.
  - Los parches de escena con Claude se acotan por contrato y `apply_patch` (Anthropic rechaza el esquema de parche por «too complex»).
  - Las llamadas Claude con imagen y salida estructurada admiten hasta 60 s por intento (el límite global de 70 s se mantiene).
  - `claude-opus-5-5` y `claude-sonnet-5-5` reconocen los niveles de esfuerzo.
  - Las conexiones Anthropic nuevas se crean con capacidad de visión; las existentes conservan su configuración.
- **Fábrica de ensamblajes 3D con registro de generadores** (`backend/spatial_assets.py`): motor monocilíndrico, iglesia gótica (11 piezas), placa de ordenador de placa única (13 piezas), tren de engranajes y arquitectura distribuida (con relaciones). El modelo elige `kind` y `scale`; Axx construye la geometría localmente. Es conceptual: no hay superficies curvas, mediciones ni física.
- **Restauración y fluidez de los tentáculos orgánicos en la órbita viva (`quickLink`):** Se corrigió la ausencia de brazos/tentáculos conectores al seleccionar herramientas alrededor de Axx. Ahora la órbita viva enlaza de forma reactiva y orgánica con el elemento enfocado o señalado (`:hover` / `:focus-within`), garantizando la extensión fluida y la retracción limpia sin interferencia de desenfoques de ventana.

## Verificación

- Pruebas de backend afectadas: 54 aprobadas (compilador visual, plan de presentación, Magic Pen HTTP, memoria HTTP, transporte espacial y ajustes de proveedor).
- Llamadas reales a Anthropic con la conexión guardada (`claude-sonnet-5-5`): respuesta mínima, verificación con imagen y esquema estructurado, y Magic Pen sobre una imagen sintética (localizar, diagrama, 3D y modificación de una pieza).
- Gate de compatibilidad de companion permanente: `python scripts/validate_companion.py --output build/companion-validation.json` aprobado en todos sus frentes (15 contratos, 111 backend móvil, 58 navegador, 8 selector desktop).
- Compilación de Windows e instalación verificada localmente.

## Limitaciones

- ChatGPT/Codex no se reprobó en esta versión porque su cuenta reportó `rate_limit_reached`.
- Claude elige por sí mismo una escena 3D libre en lugar de un ensamblaje cuando no reconoce el tema.
