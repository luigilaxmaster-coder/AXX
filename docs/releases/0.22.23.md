# Axx 0.22.23 · Entrada y secuencias completas

- La recepción del primer clic se actualiza antes de que Windows entregue el
  evento. Conserva el arrastre y el paso al escritorio fuera de Axx; usa el hilo
  de entrada existente, sin cambiar el renderizador ni el avatar.
- Una orden bloqueada por otra tarea muestra la explicación en el widget y
  conserva el borrador, en lugar de dejarla únicamente en un estado oculto.
- El campo conserva el foco mientras espera la respuesta y lo recupera después
  de activar Enviar si el usuario no cambió de control. Cerrar otro panel no
  retira la capacidad de escribir en una barra rápida que sigue abierta.
- Las secuencias admiten «y» con otros verbos, comas, líneas y «primero». Se
  separan antes de interpretar el buscador para evitar absorber mandatos
  posteriores. Comillas, negación y contenido de escritura siguen protegidos.
- El planificador recibe las cláusulas ordenadas y las restricciones de cada
  parámetro. Puede corregir una omisión, parámetros inválidos o una respuesta
  sin JSON una vez, dentro del presupuesto de dos inferencias y con el mismo
  proveedor. Un plan aún inválido o incompleto no inicia efectos.
- Las comprobaciones finales deben señalar archivos declarados o existentes;
  se rechaza antes de ejecutar una ruta inventada como «output» o un texto que
  contradiga el contenido literal. Un paso cuyos parámetros están enlazados al
  resultado anterior admite omitir el objeto vacío de entradas, conservando su
  validación y la lectura del resultado comprobado.
- La [batería de práctica](../COMMAND-TRAINING.md) cubre clic, Intro, bloqueos,
  parámetros, orden, corrección, fallo intermedio y ausencia de repetición.

Validación automatizada: 74 casos de lenguaje, secuencias, aprendizaje, contratos,
catálogo y proveedores en Linux (tres casos nativos omitidos), las tres
comprobaciones correspondientes en Windows, biblioteca de comandos (33 grupos),
escenarios de la barra rápida y 18 pruebas Rust aprobadas (un helper omitido).
La batería de Python también se ejecuta en cada push y pull request.

El paquete final fue instalado y comprobado en Windows: hashes de binarios,
registro, accesos directos, 36 avisos de licencia y backend autenticado. Cuatro
archivos privados de configuración conservaron sus hashes.

Desde su barra pequeña se verificaron el clic de ratón en Enviar, la respuesta
compacta y una segunda orden con Intro sin volver a enfocar el campo. La conexión
API seleccionada sobrevivió a la reinstalación; preparó un plan en dos inferencias
y, tras revisar sus parámetros en Axx, creó un archivo nuevo, calculó su hash y
superó la comprobación independiente del contenido. La secuencia de abrir YouTube
y buscar Faint de Linkin Park completó ambos pasos ordenados con recibos y
resultados visibles. Buscar no acredita reproducción del video.

Estos escenarios no certifican todas las aplicaciones ni todos los modelos.
Se mantienen las restricciones de servicios, credenciales, aprobaciones y
superficies protegidas. Android conserva su versión y validación independientes.
