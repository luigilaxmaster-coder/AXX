# Axx 0.22.23 · Entrada y secuencias completas

- La recepción del primer clic se actualiza antes de que Windows entregue el
  evento. Conserva el arrastre y el paso al escritorio fuera de Axx; usa el hilo
  de entrada existente, sin cambiar el renderizador ni el avatar.
- Una orden bloqueada por otra tarea muestra la explicación en el widget y
  conserva el borrador, en lugar de dejarla únicamente en un estado oculto.
- El campo conserva el foco mientras espera la respuesta y lo recupera después
  de activar Enviar si el usuario no cambió de control. Cerrar otro panel no
  retira la capacidad de escribir en una barra rápida que sigue abierta.
- Las secuencias admiten «y» con otros verbos, comas, líneas y «primero». Se
  separan antes de interpretar el buscador para evitar absorber mandatos
  posteriores. Comillas, negación y contenido de escritura siguen protegidos.
- El planificador recibe las cláusulas ordenadas y puede corregir una omisión
  simple una vez, dentro del presupuesto de dos inferencias y con el mismo
  proveedor. Un plan aún incompleto no inicia efectos.
- La [batería de práctica](../COMMAND-TRAINING.md) cubre clic, Intro, bloqueos,
  parámetros, orden, corrección, fallo intermedio y ausencia de repetición.

Validación de fuente: biblioteca de comandos (33 grupos), escenarios de la barra
rápida, 43 casos Python de comandos/aprendizaje/HTTP más las comprobaciones
focalizadas de corrección y cobertura, y 18 pruebas Rust aprobadas (un helper
omitido). La primera candidata instalada completó una consulta desde el botón
activado con teclado; no acredita el clic de ratón ni el paquete final.

La instalación final y su publicación siguen pendientes de la aceptación
instalada. Se mantienen las restricciones de
servicios, credenciales, aprobaciones y superficies protegidas. Android conserva
su versión independiente.
