# Axx 0.22.1 — comprensión de variantes de comandos

## Cambios

- Gramática española para cortesía, peticiones de intención, conjugaciones y
  destinos de búsqueda: «podrías abrirme…», «necesito que busques…», «quisiera
  abrir…» o «encuentra X en YouTube».
- Alias acotados en posiciones de destino y errores conocidos sólo para dictado.
  Se conservan las consultas, URLs y textos que se escribirán.
- Verbos de voz desconocidos con similitud alta producen sugerencias sin preparar
  operaciones. Aplicaciones de nombres cercanos se presentan como candidatas.
- Spotify acepta «quiero escuchar Spotify», «pon Spotify en pausa» y «necesito que
  pauses Spotify» mediante sus controles locales existentes.
- El API del resolvedor incluye la forma canónica cuando cambia la sintaxis.
  Interpretar no ejecuta ni demuestra el resultado.
- El trabajador ASR persistente instala una sola protección de importaciones;
  evita acumular objetos en cada turno.
- Se conservan la ejecución y los adaptadores de escritorio de 0.22.0.

## Validación

- Corpus de desarrollo: aperturas 2/13 → 13/13 y búsquedas 1/10 → 10/10 frente a
  0.22.0. No es una evaluación independiente ni una prueba física del micrófono.
- Normalización pura: p50 0,010 ms, p95 0,019 ms en 2.300 casos, sin llamadas LLM.
- Batería de backend: 401 pruebas, 4 omitidas. Comprobaciones finales focalizadas:
  61 aprobadas. Frontend: 30; biblioteca de comandos: 29.
- Dos contextos alternativos de Whisper no mejoraron consistentemente el audio
  sintético español. El contexto acústico actual se conserva.
- Compilación e instalación 0.22.1 verificadas. En el backend instalado, una
  petición con cortesía abrió Obsidian y confirmó el foco; una búsqueda con
  «me gustaría… usando YouTube» abrió la pestaña correcta. Se observaron ambas
  aplicaciones y el avatar nativo. Un verbo dudoso produjo sólo una sugerencia;
  las negaciones y preguntas informativas no crearon operaciones.
- Una muestra sintética española produjo «En Chrome Bosca YouTube.» y se resolvió
  correctamente. ASR tardó 19,266 s en esa prueba, con presión de recursos: la
  telemetría mostró 0,61 GB de disco libre y Windows rechazó nuevos procesos.
  Al cerrar la instancia de aceptación quedaron unos 3 GB libres. Esa medición
  no acredita la meta de dos segundos ni una mejora acústica.
- Instalador probado: SHA256
  69b7b27e12d1ea26901e31840c5c7910c56e986ed6220c825b33c81870a5c4a1.
