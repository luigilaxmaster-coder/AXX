# Axx 0.22.20 · Recuperación de comandos del escritorio

- Corrige el fallo por el que una pasarela AnythingMCP apagada impedía ejecutar órdenes reconocidas como «abre YouTube».
- El inicio explícito de la pasarela recuerda su distribución. Las órdenes posteriores pueden reanudar los contenedores existentes en un máximo de 35 segundos, sin descargar imágenes, crear servicios ni modificar las credenciales. Detenerla explícitamente desactiva esa recuperación.
- Revalida la red después del arranque. Una red cambiada sigue requiriendo configurar la ruta; no se sustituye por un inyector directo.
- Los fallos de transporte previos al gesto se registran como fallos, sin atribuirlos a una cancelación del usuario. Un posible efecto ya iniciado conserva el estado incierto.
- Secuencias explícitas como «abre YouTube y luego busca Faint» o «abre calculadora; abre YouTube» se preparan como un plan ordenado de hasta ocho pasos, reutilizando revisión, aprobación y parada ante fallos. No requieren que un modelo divida la frase; búsquedas, texto entre comillas y órdenes sin resolver no se ejecutan parcialmente.
- Las secuencias que necesitan interpretación se envían completas al planificador general. Una primera instrucción local ya no absorbe el resto de la frase. El plan conserva el chat de origen y se revisa antes de ejecutarse.

Las instalaciones anteriores deben iniciar una vez su pasarela para guardar la distribución. No se modifican preferencias de voz, modelos, datos ni permisos de Computer Use.

Validación de fuente: pruebas de transporte MCP, configuración, cancelación y recuperación; reanudación del servicio local existente con credenciales conservadas. La aceptación instalada se comprueba después de generar el paquete. Esto no acredita control universal de aplicaciones ni de superficies protegidas.
