# Axx 0.21.13 — transcripción local preparada

## Cambios

- El transcriptor local mantiene un único proceso y el modelo cargado entre turnos de voz. Lo prepara en segundo plano al iniciar Axx.
- Cada orden sigue usando un archivo de audio temporal acotado y se borra al terminar. Cancelar una transcripción cierra el proceso y la siguiente orden inicia uno nuevo.
- La salida del trabajador está limitada y se valida por respuesta. Si el proceso falla, se descarta antes de otro turno.
- Cuando el reconocimiento español devuelve la variante observada «And Chrome. Busca…», el chat de voz la dirige a la búsqueda tipada «en Chrome busca…». El texto reconocido queda visible; la corrección se limita al inicio de esa orden y no genera scripts.
- Se conservan el reconocimiento de comandos de escritorio y el modelo Base opcional de 0.21.12. El instalador sigue incluyendo Tiny; el Base local de este equipo no se publica.

## Verificación y límites

- En Python, una muestra sintética de «Open Spotify and search for Linkin Park» tardó 4,84 s en preparar Base, seguido de 1,97 s y 1,91 s por turno. El dictado dijo «Spatifi» y «Lincoln Park», por lo que esa muestra no demuestra reconocimiento perfecto.
- La versión 0.21.12 instalada tardó 3,70 s con Tiny y 6,22 s con Base en una muestra sintética más larga. Esos números no son comparables directamente con los de la frase inglesa más corta.
- En el backend **instalado 0.21.13**, Base tardó 1,516 s y 1,437 s en dos turnos consecutivos de la misma muestra sintética inglesa. Ambos registraron 0 ms de carga del modelo. La salida fue «Open Spatifi and search for Lincoln Park», de modo que velocidad y exactitud siguen siendo medidas separadas.
- Con voz sintética española de Axx, «Abre Obsidian» se reconoció literalmente en 1,281 s; «En Chrome busca YouTube» tardó 1,500 s, pero el modelo produjo «And Chrome. Busca YouTube». Esa observación motivó la corrección de ruta anterior y requiere repetición en el paquete final.
- En el paquete final reinstalado, Base tardó 1,391 s y 1,422 s con la muestra inglesa y 0 ms de recarga. El resolvedor instalado interpretó «And Chrome. Busca YouTube.» como búsqueda Google de «YouTube»; la acción terminó y se observó la pestaña correspondiente en Chrome. La nueva síntesis española quedó ocupada por otra generación de MOSS durante esa comprobación, por lo que la cadena completa con audio español no se repitió tras la recompilación.
- El ejecutable instalado abrió una búsqueda Google de «youtube»: la acción terminó con postcondiciones aprobadas y se observó la pestaña de Chrome. La interfaz nativa conservó el avatar 3D. Pasaron 275 pruebas de backend y 30 comprobaciones de contrato del frontend.
- La meta de primera respuesta hablada antes de dos segundos sigue pendiente de una prueba completa con micrófono, modelo de conversación y salida de audio. Abrir Spotify o su búsqueda no prueba reproducción de una pista.
