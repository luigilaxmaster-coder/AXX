# Axx 0.23.3 — Acts Studio 3.1, Equipos por Nodos, Rutinas Cron, Explicación Señalizada y Code Studio

Esta versión integra en Windows la arquitectura completa de **Acts (Evolution 3.1)**, el editor de **Equipos por nodos** con contratos por conexión, **Rutinas cron de 5 campos** conectadas al pipeline real, el motor de **Explicación Señalizada** (3D anclado, diagramas editables, guías de dibujo sobre captura y guías de líneas en código) y la selección multiarchivo/carpeta en **Code Studio**, manteniendo intactas las mejoras de MOSS-TTS modular (`0.23.2`) y las rutas `/v1`.

## Cambios principales

### 1. Acts Studio, Equipos por Nodos y Rutinas Cron
- **Identidad y renderizado propio de cada Act**: `act-avatar.js` reutiliza el renderizador real de AXX para miniaturas en biblioteca, chat, barra superior, presencias y cursor propio de computador (`axx.computer`).
- **Equipos como grafo DAG ejecutable**: conexiones entre nodos con detección de ciclos, orden topológico persistido (`team.graph`), aislamiento estricto de contexto aguas arriba, estado en vivo desde `EventHub`, **contrato de entrega (`label`)**, modo de transferencia (`full` / `summary` / `artifact_only`) y reglas/criterios del equipo aplicados en `_execute_team_pipeline`.
- **Rutinas cron profesionales**: programador de 5 campos (`next_cron_ms`, `/routines/preview`), soporte para objetivos de equipo o Act individual, y reanudación con aprobación humana explícita (`/routines/approve`).

### 2. Explicación Señalizada y Magic Pen
- **Escenas 3D ancladas**: cámara y etiquetas 2D/3D sincronizadas al mismo cuadro (`qa()`) para piezas en movimiento y exportación con verificación de IDs (`mesh_export.py` / `offline_glb.py`).
- **Diagramas y guías de dibujo**: nodos de diagrama editables (`DIAGRAM-02`) conservando su ancla y región, y detección de zonas de color más comparación tras cambios en el lienzo (`DRAW-01..03`, botón *Actualizar guías*).

### 3. Code Studio
- **Contexto multiarchivo y de carpeta**: selección múltiple de pestañas y botón *Añadir carpeta actual al contexto* (hasta 8 archivos sin credenciales mediante `CodeContextService.build`) en *Pedir a un Act*, *Delegar archivo al Act* y *Equipo Dev → QA*.
- **Guías sobre líneas reales (`axx-guide`)**: decoración por tipo (`focus`, `reference`, `error`, `flow`) con colores y bordes diferenciados en el paso activo, descartando rangos fuera del archivo.

## Verificación y alcance
- Suite de integración en Python y Playwright Chromium aprobada para guías visuales/código/dibujo (`test_guidance`, `test_guidance_ui`), grafos/contratos de equipo y rutinas (`test_team_graph`, `test_team_flow_ui`, `test_acts_ux_improvements`) y flujos de Code Studio/Acts (`test_acts_code_tools`, `test_acts_inference`, `test_acts_ui`, `test_code_studio_ui`, `test_acts_complete_handoff`, `test_act_computer`, `test_scene_document_and_diagram_studio`).
- Gate pareado de escritorio y móvil (`validate_companion.py`) y verificación de instalación nativa en Windows (`v0.23.3`) ejecutados antes de publicar.
- Las pruebas opt-in dependientes de Ollama local, sesión Codex (`AXX_REAL_CODEX=1`), movimiento físico Win32 (`AXX_REAL_COMPUTER=1`) y hardware Android separado no se certifican sin ejecutarlas en su entorno específico.
