# Axx 0.22.11

Computer Use tiene una pantalla propia, accesible desde Asistencia → Controlar
PC, la cabecera del chat y Datos y sistema. La guía distingue tres pasos:
comprobar ChatGPT y el modelo, buscar y seleccionar una ventana, y otorgar las
dos autorizaciones para ese chat. No selecciona una ventana ni marca permisos
automáticamente. Abrir Conectar IA navega a la pestaña ChatGPT; la conexión y
la prueba del modelo siguen siendo explícitas.

La autorización existente se recupera al abrir la pantalla. Cambiar de chat o
proveedor revoca el acceso, incluso si el cambio ocurre durante la autorización.
Los errores de conexión, ventanas vacías y permisos pendientes muestran el paso
que falta. El chat conserva un acceso visible y el estado de Computer Use.

El historial instalado registró dos observaciones fallidas por timeout de UI
Automation. El worker agrupa ocho propiedades de cada control en CacheRequest
en lugar de consultarlas repetidamente. Se mantienen el límite de tiempo,
la identidad y geometría de la ventana, la exclusión de controles protegidos
y la verificación posterior. Esta optimización no garantiza que un proveedor
de accesibilidad bloqueado responda; no se ha medido una mejora de latencia nativa.
Referencia del mecanismo: [Microsoft CacheRequest](https://learn.microsoft.com/en-us/dotnet/api/system.windows.automation.cacherequest?view=netframework-4.8.1).

La última operación fallida aparece en la configuración y en el estado del chat.
Un efecto incierto exige revisión y no se repite. Detener revoca la autorización;
no revierte efectos realizados. Se conservan los límites de 15 minutos y 60 gestos.
No se añaden botones al grupo de tres accesos del avatar ni se cambian sus motores,
materiales, calidad, ajustes o datos.

Validación de fuente: 28 pruebas Python de observación y permisos; contrato
PowerShell con controles sintéticos que rechaza lecturas de metadatos sin agrupar
y verifica exclusión de contraseña; pruebas de navegación real de la interfaz,
modelo verificado, consentimiento, recuperación, cambio de chat y diagnóstico;
regresiones de entrada rápida y dictado con audio sintético aprobadas.
La instalación y aceptación nativa se registran por separado. No se han concedido
permisos de Computer Use ni enviado capturas de otras aplicaciones como prueba.

Entrega Windows: instalación 0.22.11 y arranque verificados; backend autenticado,
superficie nativa marcada visible y archivos coincidentes con el build. Respaldo
local de 580 archivos con CRC y bases SQLite comprobados. La prueba visual fue
detenida mediante Escape antes de la instalación; no se realizó más automatización
de ventanas. Falta la aceptación de una tarea completa sobre una ventana que el
usuario seleccione y autorice manualmente; no se acredita con las pruebas de fuente
ni con el recibo de arranque.
